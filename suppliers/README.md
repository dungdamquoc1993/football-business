# Nhà cung cấp

- [XStars](xstars/README.md): hai báo giá PDF gốc, ghi chú theo dòng giày và
  điều khoản bảo hành đã trao đổi.

Mỗi nhà cung cấp có một thư mục riêng. Hồ sơ nhà cung cấp giữ báo giá, điều khoản
và nguồn xác nhận; `quotes/` giữ tài liệu gốc, `products/` giữ ghi chú sản phẩm.
Không dùng hồ sơ này thay tồn, giá bán, phiếu nhập hoặc tình trạng thanh toán
hiện hành trong Admin MCP. Ảnh thuộc [photo workshop](../photo-workshop/README.md).
